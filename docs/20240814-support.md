# SAI2 2024.08.14 适配

此分支从原 main（`3190a0c`）继续开发。提供的是 C# / WPF 主题工具源码，入口为 `src/MainTheme.cs`，颜色写入逻辑为 `src/tools/ThemeS2CE.cs`。SAI 本体只有 `ref/sai2.exe` 二进制，没有 SAI 自身源码。

1.4.1 使用简化的中文启动器：选择 SAI2、选择主题卡片、生成并启动；支持六组 RGB 自定义配色、选色器、实时预览、用户主题编辑和另存，统一深色滚动条并支持卡片区域滚轮，同时记住选择并提供独立恢复入口。换肤生成独立 EXE/INI，原文件保持不变。操作方式见 [自动识别版本与独立换肤副本](multiversion-copy.md)。

## 构建与使用

构建需要 Windows 和 .NET 8 SDK；默认生成的程序需要 .NET 8 Desktop Runtime。加上 `-SelfContained` 可生成自带运行时的 x64 测试包。

在仓库根目录运行以下命令，生成独立的新目录。脚本只读取输入 EXE，不修改原安装，也不复制授权文件或个人设置。

```powershell
.\tools\package_20240814.ps1 -SaiExecutable 'C:\[Saier]SAI Ver.2\sai2.exe'
# 无需另装运行时：
.\tools\package_20240814.ps1 -SaiExecutable 'C:\[Saier]SAI Ver.2\sai2.exe' -SelfContained
```

输出目录在 `dist`，路径会显示在命令最后。打包时必须在输入 EXE 旁保留对应的 `sai2.ini`，它会一起复制，以保留汉化版的语言配置，避免英文界面和笔刷乱码。运行输出目录的 `S2CE.exe`，选择自己原安装目录中的 EXE 后即可使用原目录的资源和授权。如果使用包内的 SAI 副本，需把自己的合法授权放在包内 `ref`。原仓库中的 `ref/sai2.exe` 继续保留 2024.02.22 基线，普通 `dotnet build` 的默认输出也包含这个旧版；上述打包脚本可生成新版包，两者都能在界面中重新选择其他受支持的构建。

新版界面生成 `sai2-colored.exe` 和配套 INI，并通过状态记录验证归属。每次换主题都读取原文件；classic 清理校验通过的副本后启动原版。若从 1.1.0 测试包升级，先使用旧包的 classic 还原 `ref/sai2.exe`，保留原始备份；已经被旧工具修改的 EXE 不会被当作原版放行。请在 SAI 已关闭时换肤。

## 修改内容

- 按精确 EXE 哈希选择 `Address.json` 或 `Address.20240814.json`。
- 迁移全部 294 个地址项：255 个皮肤地址/范围边界、28 个代码颜色常量、5 个滑块颜色表地址、6 个全局区段边界。
- 完整核对 `.appskin` 和 `.srclibs`，两版只存在内部指针重定位差异，其他载荷相同；代码地址使用唯一指令上下文匹配。
- 等待四个色环处理区域全部完成，再进行后续换肤和保存，修复后台线程尚未完成就保存/退出的问题。
- 写入前核验当前文件和备份归属；通过同目录临时文件替换 EXE，避免直接截断目标。
- 启动时从工具所在目录读取资源；界面显示错误并允许重试。
- 20240814 的三个界面文字转换调用改为使用主题文字色作为默认黑色的替代值，修复深色对话框、工具面板及输入框文字不可读。使用已验证的 17 字节空白代码区，不修改 PE 布局或全局颜色转换函数；画布绘制路径保留原调用。
- 输入框选中背景根据主题文字亮度选择黑色或白色，提高选中文字的对比度。

## 验证

以下测试使用临时副本，不启动 SAI，不修改原安装或授权文件：

```powershell
dotnet run --project tests\Compatibility -c Release -- 'C:\code\sai2-colored-edition' 'C:\[Saier]SAI Ver.2\sai2.exe' 'D:\ai_tmp\s2ce-compat-evidence'
```

2026-10-24：两个版本的 66 项断言全部通过，覆盖新版实际地址写入、代码颜色、未涉及区段保持原样、重复换肤、切换主题、色环结果确定性、精确还原，以及未知构建/冲突备份/被改动的文件不写入。Release 构建通过。

额外反汇编验证使用 Python 的 `capstone` 开发依赖：

```powershell
python tools\verify_patched_binary.py 'C:\[Saier]SAI Ver.2\sai2.exe' 'D:\ai_tmp\s2ce-compat-evidence\2024.08.14-patched.exe'
```

两版测试主题的常规颜色修改均改变 34 个函数中的 55 条指令，改动全部位于立即数操作数内。新版另外验证三个界面文字调用、17 字节辅助函数及选中背景色，检查通过后再单独核对其余代码。PE 头和其他受保护区段保持原样。

已在 Windows 沙盒实际运行 20240814，验证 cappuccino、retro 和 classic 还原；完成黑/红笔画、撤销重做、文字图层、新建图层、SAI2 保存重开及 PNG 导出。深色主题与经典还原后的 PNG 像素完全一致；还原后的 EXE 与输入文件 SHA-256 一致。截图、复现步骤和验证边界见 [界面实测报告](20240814-ui-validation.md)。数位板压感、长时间大文件和其他 DPI 尚未验证。

地址表可用 `tools/generate_version_addresses.py` 从本地两个 EXE 重新生成；该工具需要 `capstone`，拒绝有歧义的代码上下文和无法解释的皮肤载荷变化。正常运行主题工具不需要 Python。
