# SAI 2 - Colored Edition v1.0.0

Меняйте цвета интерфейса SAI2, создавайте собственные темы и сохраняйте исходную программу.

[Скачать](https://github.com/yaya-ccc/sai2-colored-edition/releases) · [Сообщить об ошибке](https://github.com/yaya-ccc/sai2-colored-edition/issues)

## Использование

1. Распакуйте пакет, сохраните все его файлы и запустите `S2CE.exe`. Обычному пакету нужен .NET 8 Desktop Runtime; автономному — нет.
2. Закройте SAI, нажмите **选择程序…** («Выбрать программу») и укажите исходный `sai2.exe`. Его INI должен находиться рядом.
3. Дождитесь статуса **可换肤** («Поддерживается») и выберите карточку темы.
4. Нажмите **生成主题并启动 SAI** («Создать тему и запустить SAI»). Инструмент создаст отдельную копию, сохранив исходные EXE и INI.

Лаунчер запоминает выбор. В дальнейшем можно запускать `sai2-colored.exe` прямо из каталога SAI.

Поддерживаются проверенные сборки **2024.02.22 x64** и **2024.08.14 x64 с локализацией**. Совместимость вашего EXE определяет лаунчер.

## Настройка цветов

- Выберите готовую тему и нажмите **自定义配色…** («Настроить цвета»). Измените шесть цветов через образцы или ввод `#RRGGBB`.
- Введите название и нажмите **保存主题** («Сохранить тему»).
- Для изменения пользовательской темы нажмите **编辑配色…** («Изменить цвета») или дважды щёлкните по карточке. **保存修改** («Сохранить изменения») обновляет тему; **另存为…** («Сохранить как») создаёт отдельную копию.
- Вернитесь в главное окно и нажмите **生成主题并启动 SAI**, чтобы применить сохранённую палитру.

![Редактор темы](docs/screenshots/theme-editor.png)

Темы хранятся в `%LOCALAPPDATA%\S2CE\themes`. Для обмена отправьте JSON из этой папки. Получатель помещает файл в свой каталог пользовательских тем и заново открывает лаунчер.

## Возврат к оригиналу

Закройте SAI и нажмите **恢复原版并启动** («Восстановить и запустить оригинал»). Инструмент удалит проверенную копию с темой и запустит исходную программу.
