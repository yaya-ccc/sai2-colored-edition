# 版本数据 / Build data / Данные сборок

## 中文

此目录由程序读取，使用时保持完整，无需手动修改。选择原版 `sai2.exe` 后，工具会自动检查是否支持；显示“可换肤”后即可选择主题并启动。

更改配色请使用主界面的 **“自定义配色…”** 或 **“编辑配色…”**。旧地址资料保存在[历史笔记](../../../docs/legacy-address-notes-20240222.md)。

## English

Keep this directory intact; no manual changes are needed. Select your original `sai2.exe` and let the launcher check compatibility. Once it shows **可换肤** (Supported), choose a theme and launch SAI.

Use **自定义配色…** (Customize colors) or **编辑配色…** (Edit colors) to change the palette. Earlier address research is kept in the [historical notes](../../../docs/legacy-address-notes-20240222.md).

## Русский

Сохраните этот каталог целиком; изменять файлы вручную не нужно. Выберите исходный `sai2.exe`, чтобы лаунчер проверил совместимость. После появления **可换肤** («Поддерживается») выберите тему и запустите SAI.

Для настройки палитры используйте **自定义配色…** («Настроить цвета») или **编辑配色…** («Изменить цвета»). Старое исследование адресов сохранено в [архиве](../../../docs/legacy-address-notes-20240222.md).
